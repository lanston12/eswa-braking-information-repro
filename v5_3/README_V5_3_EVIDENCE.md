# V5.3 numerical-resolution evidence

This folder contains the eight source CSV files supplied for the V5.3 run, the V5.3 MATLAB source and its documentation, and all four V5.3 PDF figures.

The reported run is the V5.3 `standard` configuration: 10 replications, 100 planning draws and 200 independent test draws per replication; feature-error half-width 0.05 m/s^2; clock-jitter half-width 0.02 s; fee 0.70 m-equivalent; N_tau = 21, 51, 101, 201, 401.

These are three fixed synthetic physical-model designs. They are not independent measured truck fleets. The supplied CSVs, not pixel readings from the plots, are the numerical source for Supplement P. The two policy/action PDFs are retained for audit only and are not included in the manuscript because their original figure layouts are crowded.
